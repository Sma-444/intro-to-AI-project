Comparing with the regular FNN layer we learnt before, the special points in a convolutional layer are mainly shared weights and local window. We illustrate this idea with an example convolutional layer with  1D input .
The input image has one color channel with 4 pixels. It is flattened to a 1D array and then fed to the input layer.
The conv layer has 1 kernel with two weights  .

SLIDE 71
Padding  → adds extra pixels (usually zeros) around the borders of the input → helps control / prevent shrinking of the output size and preserves border information.
Stride  → controls how many pixels the filter jumps / skips after each position → used to reduce ( downsample ) the output size and increase the receptive field quickly.

✅  What is the Degradation Problem?
In deep learning, it's intuitive to think:   The deeper the network, the better its representational capacity, and thus the lower the training error.
However, in practice:
  When we increase the number of layers in a plain deep neural network (e.g., beyond 20 or 50 layers),
  Training error actually increases , which is unexpected.
  This is  not caused by overfitting , since it happens on the training set itself.
  Instead, it's a symptom of optimization difficulties — gradients may vanish, explode, or become unstable.
This phenomenon is called the  degradation problem .

✅  Why Is This Effective?
   The identity mapping  x→x  is easy to learn.
   If some layers are not needed, the network can simply learn F(x)   =   0, effectively skipping them.
  Thus, deeper networks behave no worse than shallower ones — avoiding degradation.
  This enables building very deep networks ( e.g. , ResNet-50, ResNet-101) with good performance.
