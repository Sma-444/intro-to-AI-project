# 相似度、泛化与更深视觉微调实验

日期：2026-11-20。

## 0.676的含义

现有DINO候选的 **0.675967336来自2500张Validation图片**。它没有训练这些验证图文对，但训练早停、选checkpoint和多次方案选择都用到了这个验证集，所以验证集并非完全独立的最终测试。

对第i张图片，令生成描述为c_i、参考描述为r_i，使用课程冻结的all-MiniLM-L6-v2得到384维句向量。实际处理是tokenizer截断到64个token，对非padding token隐藏状态做均值池化，再L2归一化。分数为：

`s_i = dot(E(c_i), E(r_i)) / (norm(E(c_i)) * norm(E(r_i)))`

`S = (1/N) * sum(s_i)`

归一化后只需计算向量点积。余弦理论范围为[-1,1]；越接近1表示向量方向越一致，但这不是概率，也不是“描述正确率”。0.676不表示67.6%图片正确，更不能说0.7就代表70分。

评分器只读取两句文字，不读取图片。它奖励语义接近和参考强调的信息，但不能可靠检查每个视觉事实：合理但侧重点不同的描述可能分低，主体相同但关系/颜色错误的描述仍可能有一定相似度。该指标也受参考描述的详细程度与表述方式影响。

README规定：Training12000、Validation2500、Test2625；图片来自VOC2012。正式评估比对提交的测试预测与老师持有的测试参考。没有证据表明老师一定另用完全不同来源的图片集。测试分数P和教师基线Q通过 `R=(P-Q)/(1-Q)` 转成性能分档，再结合代码和报告部分给分；当前Q未知，不能用验证0.676直接算正式成绩。

同来源测试成绩可能与验证较接近，但README未给出随机切分/分布一致的保证。若换成医学、卫星、商品、极端视角等其他图片分布，或参考描述风格变化，成绩可能下降。无法从现有分数推导“任意其他测试集也高分”或可信的测试分数范围。

现有DINO对ResNet Transformer的逐图提升0.0801及低分样本减少，是改进有价值的证据；此前paired bootstrap区间只反映这2500张验证图片上的条件波动，不是隐藏测试分数的置信区间，也不反映训练种子的变化。

后续坚持：训练参数只拟合Training；MiniLM只作Validation评分；Test只在最终选择后生成预测；控制预先声明的实验数量，保留原候选，不能通过重复调验证把分数当作独立泛化证明。第二种子可检查训练稳定性，但仍不能替代隐藏测试。

## 预先确定的实验

control：`runs/dinov2_transformer_v1`，seed2205、最后2个DINO block与输出LayerNorm从第3轮开始微调，视觉LR1e-5，其余配置见DINO实验说明。

candidate：`runs/dinov2_transformer_tail4_v1`，同一数据、初始预训练权重、词表、seed、输入变换、文本decoder、batch、总训练预算、调度器和beam3策略。唯一有意变动是视觉尾部微调策略：从最后2个block扩大到最后4个，新增加的第9/10个block使用LR5e-6，原最后两个和输出LayerNorm仍用1e-5。从头初始化文本模块重新训练，不从已用验证选出的best checkpoint继续拟合。

最多16轮、patience4；如果独立重载提升达到0.003，则对control和candidate都补一个相同的新seed2206，检查方向是否稳定。0.003仅是追加计算的工程门槛，不是统计显著性界限。不为了达到0.7而不断扫描seed。低于门槛则保留原候选并记录失败/不确定结果。

已完成preflight：明确验证DINO前8个block冻结、后4个可训练，冻结参数不变、解冻参数更新；24张训练图三步AMP loss为7.4225、6.8536、6.5405。因果mask、padding、前缀一致性、beam batch独立性、严格重载和旧模型兼容性通过，体积仍约103.29MB。

运行：

```powershell
$env:PYTHONPATH=(Resolve-Path 'captioning/.env/site-packages').Path
python captioning/train_transformer.py --backbone dinov2_small --encoder-lr 1e-5 --visual-tail-blocks 4 --extra-encoder-lr-scale 0.5 --output-dir captioning/runs/dinov2_transformer_tail4_v1
```

## 结果

已完成16轮训练并独立重载最佳权重，对全部2500张验证图片评分。

| 方案 | 最佳epoch | 独立验证相似度 | checkpoint大小 |
|---|---:|---:|---:|
| 原方案：最后2个DINO block | 11 | **0.675967336** | 103,290,761 bytes |
| 新方案：最后4个DINO block，新增两层半学习率 | 14 | 0.674344242 | 103,290,761 bytes |

新方案比原方案低 **0.001623094**。训练时最佳CSV与独立重载CSV全部2500条描述逐条一致，分数一致；严格加载、ID覆盖、非空描述与文件大小检查均通过。训练日志记录第9、13轮AMP自动跳过各一次溢出更新，没有中断。

本轮**不替换**0.675967336候选。未满足预先设定的+0.003门槛，因此不追加第二种子的control/candidate训练；不能声称已证明跨随机种子稳定。差异本身很小，也不能据此断言更深微调在所有配置上都不行。正确结论是：本次指定微调配方没有改善当前验证结果。

新配方第16轮训练loss约1.0388，原配方第15轮约1.0983，但新配方最佳验证分数更低，说明训练拟合改善并不必然带来验证改善。这是本次不继续扩大解冻范围的依据。

候选完整记录：`runs/dinov2_transformer_tail4_v1/{training_history.csv,config.json,verification.json,comparison.json}`，最佳checkpoint仍保留以供审查。Test未参与选择，根目录提交模型/预测保持原样。

后续候选方向为提高图像细节保留（例如独立的较高分辨率试验，保持decoder和微调范围固定），而非继续无约束地加深微调。该后续试验本轮未执行，不能报作已取得提升。
